## 📖 Proje Hakkında / About
**TR:** Ruh Durağı, kullanıcı deneyimi (UX) odaklı tasarlanmış modern bir frontend web platformudur. Kullanıcıların ruh sağlığı uzmanlarını kategorilere göre filtreleyip incelemesine ve randevu süreçlerini yönetmesine olanak tanır.

**EN:** Ruh Durağı is a modern frontend web platform designed with a focus on user experience (UX). It allows users to filter and examine mental health experts by category and manage their appointment processes.

---

## ✨ Özellikler / Key Features
- 🩺 **Dinamik Uzman Listesi / Dynamic Expert List:** Klinik psikolog, çocuk ve ergen uzmanları gibi kategorilere göre filtreleme sistemi. / Filtering system by categories such as clinical psychologists and child/adolescent specialists.
- 👤 **Detaylı Profiller / Detailed Profiles:** Uzmanların özgeçmiş, eğitim bilgileri ve danışan yorumlarını içeren kapsamlı sayfalar. / Comprehensive pages including expert resumes, education details, and client reviews.
- 📅 **Randevu Yönetim Paneli / Appointment Dashboard:** Kullanıcıların aktif randevularını görebileceği ve yönetebileceği şık bir panel. / A stylish panel where users can view and manage their active appointments.
- 🔐 **Modern Giriş Ekranı / Modern Login Screen:** Sosyal medya (Google) entegrasyonu simülasyonu içeren responsive giriş sayfası. / Responsive login page featuring social media (Google) integration simulation.
- 📱 **Tam Duyarlı / Fully Responsive:** Mobil, tablet ve masaüstü cihazlarla tam uyumlu arayüz. / Fully compatible interface with mobile, tablet, and desktop devices.

---

## 🛠️ Kullanılan Teknolojiler / Tech Stack
* **HTML5:** Semantik yapı ve içerik yönetimi / Semantic structure and content management
* **CSS3:** Flexbox, Grid sistemleri ve özel animasyonlar / Flexbox, Grid systems, and custom animations
* **JavaScript (ES6+):** Sayfalar arası veri aktarımı ve filtreleme algoritmaları / Inter-page data transfer and filtering algorithms
* **FontAwesome:** Profesyonel ikon setleri / Professional icon sets
